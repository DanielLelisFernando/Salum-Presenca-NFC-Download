# Salum-Presenca-NFC-Download
Este é um aplicativo desenvolvido para facilitar o controle de participação dos colaboradores em DDS, treinamentos, integrações, campanhas e demais atividades. Consiste no cadastro da atividade, com informações como obra, carga horária, responsável e conteúdo abordado, seguido da leitura dos crachás por aproximação com tecnologia NFC.
